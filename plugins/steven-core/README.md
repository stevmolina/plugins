# steven-core

Shared rules that Steven's other plugins load instead of repeating them.

- `steven-approval`: nothing is published, sent or paid without Steven's explicit yes on the exact text, destination and action.
- `steven-voice`: how Steven writes. Commas instead of periods, spicy and relatable but never arrogant, no templates, news first, real facts only.

Install it from the [marketplace](../../README.md), or load a skill folder directly in any agent that reads `SKILL.md` files.
